🐾 GATO_TASKBAR v1.0
Dale vida a tu escritorio con un pequeño compañero. Este proyecto añade un gatito animado que se desplaza por tu barra de tareas, haciendo que tu entorno de trabajo sea mucho más ameno y visualmente agradable.

🚀 Características
Animación fluida: Un gatito con movimiento constante en la barra de tareas.

Ligero: Ejecutable optimizado para no consumir recursos del sistema.

Construcción Automatizada: Desarrollado en Python y compilado mediante GitHub Actions usando flujos de trabajo .yml.

📥 Instrucciones de Descarga
Para obtener el ejecutable de forma segura, sigue estos pasos:

Ve a la pestaña Actions en la parte superior de este repositorio.

Busca y selecciona el flujo de trabajo más reciente llamado rename build.yml.

Desliza hacia abajo hasta la sección de Artifacts.

Haz clic para descargar el archivo comprimido que contiene el ejecutable (.exe).

🛠️ Instalación y Uso
Una vez descargado, el proceso es simple:

Extrae el contenido del archivo .zip.

Ejecuta el archivo .exe.

¡Disfruta de tu nuevo compañero de escritorio! 🐈

Nota: Al ser un ejecutable creado con Python, es posible que algunos antivirus den una falsa alerta. Puedes ejecutarlo con total confianza.

💻 Detalles Técnicos
El núcleo de este proyecto se basa en:

Lógica: Archivo principal en .py.

CI/CD: Automatización de compilación mediante archivos .yml.

Desarrollado con ❤️ para mejorar la estética de tu espacio de trabajo.
