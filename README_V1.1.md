# 🐾 GATO_TASKBAR v1.1

![Version](https://img.shields.io/badge/Version-1.1-blueviolet?style=for-the-badge)
![Status](https://img.shields.io/badge/Status-Updated-success?style=for-the-badge)

¡La evolución de tu compañero de escritorio ha llegado! En esta **versión 1.1**, hemos dejado atrás el diseño geométrico para dar la bienvenida a un **elegante gato negro** con una personalidad mucho más vibrante y un set de animaciones expandido.

---

## ✨ Novedades de la v1.1

* **Nuevo Diseño:** Ahora el compañero es un gato negro detallado, abandonando el estilo geométrico anterior.
* **IA de Comportamiento:** El gato ya no solo se mueve; ahora interactúa con su entorno mediante diversas acciones aleatorias.
* **Icono Actualizado:** Nuevo icono representativo para la aplicación.

---

## 🎭 Repertorio de Animaciones

| Animación | Descripción |
| :--- | :--- |
| **🚶 Caminar** | Pasea de un lado a otro de la barra de tareas. |
| **😺 Sentarse** | Entra en estado de reposo con un tierno parpadeo. |
| **🦘 Saltar** | Realiza saltos divertidos con las patas abiertas. |
| **🤸 Estirarse** | Se estira hacia adelante para desperezarse. |
| **🐾 Jugar** | Da pequeños manotazos a una pelotita invisible. |
| **🙌 Pararse** | Se sostiene momentáneamente sobre sus dos patas traseras. |
| **🕵 Acechar** | Se arrastra agachado como si estuviera cazando algo. |
| **🛁 Lavarse** | Se lame la patita para mantenerse impecable. |

## 🚀 Cómo Actualizar y Ejecutar

Para disfrutar de estas nuevas funciones y el cambio de apariencia, sigue este procedimiento:

1.  Dirígete a la sección de Actions en el repositorio.
2.  Busca y selecciona la opción:  
    > **`update gato_taskbar.py`**
3.  Una vez finalizado el proceso, descarga el nuevo ejecutable generado y ábrelo para ver a tu nuevo gato negro en acción.
